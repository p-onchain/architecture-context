# architecture-context

Architecture context pack for AI coding agents working on BlackSwan (Paribu v6) services.

## Purpose

When a developer uses Claude Code, Codex, or any AI coding agent on a specific microservice, the agent only sees that repo. This context pack provides the broader architecture knowledge — service map, communication patterns, shared conventions — so the agent can make informed decisions.

## Usage

### Option 1: Global Claude context (recommended)
Add to your `~/.claude/CLAUDE.md`:
```
When working on any BlackSwan/Paribu service, refer to ~/architecture-context/ for:
- INDEX.md — system overview, service map, communication graph
- services/<name>.md — details about specific services
- flows/<name>.md — end-to-end business flows
- conventions.md — coding standards and shared patterns
```

### Option 2: Per-repo reference
Add to a repo's `CLAUDE.md`:
```
For broader architecture context, see ~/architecture-context/INDEX.md
```

## Design Principles

1. **Modular** — agent reads INDEX.md first, drills into specific files only when needed
2. **Lightweight** — no giant text blobs. Each file is focused and concise
3. **English only** — consistent language for code-adjacent docs
4. **Agent-friendly** — structured for LLM consumption (tables, clear headers, code blocks)

## Keeping Fresh

This pack should be updated when:
- New services are added or removed
- Service communication patterns change
- Kafka topics are added/renamed
- Proto contracts change significantly
- Infrastructure changes (new DBs, messaging systems, etc.)
