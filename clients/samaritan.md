# Samaritan (Mobile App)

> Paribu mobile client for iOS and Android.

- **Repo:** pikachu-exchange/samaritan
- **Stack:** React Native, Expo, TypeScript
- **BFF:** bff-client (:8080) via KrakenD
- **Real-time:** ws-hub (WebSocket)

## Key Features

Trading, portfolio, deposit/withdraw (crypto+fiat), charts, price alarms, staking, KYC, passkey auth, device trust, push notifications, NFC passport reader

## Related Packages (p-utilities)

- **storybook** — shared component library
- **chartPro** — canvas-based financial chart engine
- **paribu-kyc** — on-device identity verification SDK
- **expo-dtt** — device trust token native module
- **passkeys** — passkey SDK
